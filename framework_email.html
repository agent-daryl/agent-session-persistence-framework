AI Agent Memory Framework

How to stop LLM agents from forgetting everything

The Problem: LLMs are stateless. Each session starts blank. Without scaffolding, agents hallucinate context, lose track of work, forget tools, and waste tokens re-learning what they already know.

The Solution: Three-Layer Memory System

A lightweight (< 4,000 tokens) system that gives agents persistent memory across sessions, dramatically reducing hallucinations and wasted context.
1

AGENTS.md — Static Identity

Ground Truth — Read-Only

Immutable reference. Defines who the agent is who the user is and what infrastructure exists. Updated only when reality actually changes.

Model Identity User Profile Architecture Tool Inventory
2

session_state.json — Working Memory

Short-Term — Updated Each Session

Survives shutdown. Tracks recent work, pending tasks, tool health, and ephemeral context. Under 3 KB — cheap to load.

Recent Work Pending Tasks Tool Status Action Items
3

knowledge_graph.yaml — Structured Knowledge

Long-Term — Queryable Knowledge Base

Typed entities, weighted relationships, attention scores. Inspired by OpenCog Atomspace. Gives the agent a structured mental model instead of a flat text dump.

Typed Entities Weighted Edges Attention Scores Projects & Goals

How It Loads at Session Start

↓ Read AGENTS.md

"Who am I? Who is my user? What tools do I have?"

↓ Read session_state.json

"What was I doing? What's still pending?"

↓ Query knowledge_graph.yaml

"What projects exist? What matters most?"

Total load: ~4,000 tokens out of 256k context. Leaves 252k+ tokens for actual work.

What Each Layer Prevents

Hallucination Layer That Fixes It
"I forgot who the user is" AGENTS.md
"I don't remember what I was working on" session_state.json
"I invented a tool that doesn't exist" AGENTS.md
"I forgot project status" knowledge_graph.yaml
"I duplicated data across files" Schema notes in all 3
"I lost track of priorities" Attention weights
